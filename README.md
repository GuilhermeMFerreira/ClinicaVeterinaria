#  Clínica Veterinária

Sistema desenvolvido para auxiliar no gerenciamento de uma clínica veterinária, permitindo organizar informações relacionadas aos animais, seus responsáveis e aos atendimentos realizados.

##  Sobre o projeto

O **Clínica Veterinária** é um projeto desenvolvido com o objetivo de aplicar conceitos de desenvolvimento de sistemas e gerenciamento de informações em um ambiente de clínica veterinária.

A proposta é facilitar a organização dos dados da clínica e tornar o gerenciamento das informações mais simples e eficiente.

##  Objetivos

* Organizar as informações da clínica veterinária;
* Facilitar o gerenciamento dos dados dos animais;
* Manter informações dos responsáveis pelos animais;
* Organizar os atendimentos veterinários;
* Aplicar conceitos de programação e desenvolvimento de sistemas;
* Desenvolver uma solução simples e funcional para uma clínica veterinária.
